## Đăng ký
- (https://kaleidofinance.xyz/testnet?ref=227KEUN1)

## 🌟 Tính năng

- **Hỗ trợ khai thác nhiều ví**: Quản lý đồng thời nhiều ví.
- **Bảng điều khiển thu nhập theo thời gian thực**: Theo dõi thu nhập của bạn theo thời gian thực.
- **Đang chờ xử lý tự động → Chuyển đổi có trả phí**: Tự động chuyển đổi thu nhập đang chờ xử lý thành số dư đã thanh toán.
- **Triển khai thuật toán băm lượng tử**: Tối ưu hóa cho khai thác lượng tử.
- **Tự động thử lại với thời gian lùi theo cấp số nhân**: Xử lý các sự cố mạng một cách khéo léo.
- **Thống kê và phân tích khai thác chi tiết**: Nhận thông tin chi tiết về hiệu suất khai thác của bạn.
- **Khả năng tương thích đa nền tảng**: Hoạt động trên Windows, macOS và Linux.

## 🚀 Cài đặt

1. Sao chép kho lưu trữ:
   ``` bash
   git clone https://github.com/anht3k52/KaleidoFinance-Auto-Bot.git
   cd KaleidoFinance-Auto-Bot
   ```
2. Cài đặt phụ thuộc:
   ``` bash
   npm install
   ```
3. Tạo tệp wallets.txt và thêm địa chỉ ví của bạn (mỗi dòng một địa chỉ):
   ``` bash
   nano wallets.txt
   ```
4. Chạy Bot
   ``` bash
   npm start
   ```
